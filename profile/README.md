### What we're building

Before every game, stream or workday, people spend minutes adjusting things by hand in apps that don't talk to each other. Nexum turns that into **modes**: a list of actions you pick from, with no code, that run in one click.

- **Brand-agnostic:** Steam, Epic, GOG, Philips Hue and more from the same mode.
- **No-code:** a mode is a list of choices, never a script.
- **Transparent:** every step reports its result, so you see what worked and what failed.
- **Lightweight:** built in Rust with Tauri.

Nexum is in development. A working desktop prototype exists today, and a closed beta is planned for 2027.
